# Инструкция по запуску автотестов YouGile API

Перед запуском тестов необходимо сгенерировать ваш личный API-ключ  и добавить его в код.

## Шаг 1: Получение ID компании (companyId)
Отправьте POST-запрос через Postman или cURL:
• URL: https://yougile.com
• Headers: Content-Type: application/json
• Тело запроса (JSON):
{
  "login": "ВАШ_EMAIL",
  "password": "ВАШ_ПАРОЛЬ",
  "name": "НАЗВАНИЕ_ВАШЕЙ_КОМПАНИИ"
}

Из ответа  скопируйте полученный параметр "id".

## Шаг 2: Получение API-ключа
Отправьте второй POST-запрос:
• URL: https://yougile.com
• Headers: Content-Type: application/json
• Тело запроса (JSON):
{
  "login": "ВАШ_EMAIL",
  "password": "ВАШ_ПАРОЛЬ",
  "companyId": "ID_ИЗ_ШАГА_1"
}

Из ответа скопируйте значение "key" (ключа).

## Шаг 3: Настройка проекта
1. Откройте файл `api_client.py`.
2. Найдите переменную `my_key`.
3. Вставьте ваш ключ внутрь кавычек: my_key = "ваш_ключ"

## Шаг 4: Запуск тестов
В терминале  выполните команду:
pytest -s
