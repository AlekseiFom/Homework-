# Проект автоматизированного тестирования

Учебный проект для демонстрации автотестов на Python с использованием `pytest` и отчётности в Allure.

## Требования

- Python 3.x
- Установлены зависимости проекта (pytest, allure-pytest и др.).
- Установленный Allure Commandline (для просмотра отчёта).

## Структура проекта

- `lesson_10/` — тесты и вспомогательные модули для урока 10
- `allure-results/` — результаты прогона тестов (генерируются автоматически)
- `allure-report/` — сгенерированный HTML-отчёт Allure (генерируется автоматически)

Папки `allure-results` и `allure-report` добавлены в `.gitignore`, поэтому содержимое отчёта в репозиторий не пушится (можно хранить только пустые папки).

## Запуск тестов с формированием отчёта

Из корня проекта выполните команду:

```bash
pytest lesson_10 -v --alluredir=allure-results
```

- `lesson_10` — папка с тестами.
- `--alluredir=allure-results` — путь к директории, в которую будут сохранены результаты для Allure.

После выполнения команды в папке `allure-results` появятся файлы результатов прогона тестов.

## Генерация HTML-отчёта Allure

После получения результатов выполните команду:

```bash
allure generate allure-results -o allure-report --clean
```

- `allure generate` — создаёт HTML-отчёт из результатов.
- `allure-results` — папка с результатами тестов.
- `-o allure-report` — папка, в которую будет сгенерирован отчёт.
- `--clean` — предварительно очищает целевую папку.

В результате в директории `allure-report` будет сформирован HTML-отчёт.

## Просмотр отчёта

### Вариант 1. Через команду Allure

Самый простой способ — запустить встроенный сервер Allure и открыть отчёт в браузере:

```bash
allure serve allure-results
```

Эта команда сама:
- сгенерирует отчёт во временную директорию;
- поднимет локальный веб-сервер;
- откроет отчёт в браузере по умолчанию.

### Вариант 2. Открыть уже сгенерированный отчёт

Если отчёт уже сгенерирован в `allure-report`, его можно открыть командой:

```bash
allure open allure-report
```

Команда запустит локальный сервер и откроет страницу отчёта в браузере.
